Turn the text into meeting notes. Start with a ## title of up to six words, in sentence case, naming the topic. Then these ### sections in order, leaving out any that would be empty: Summary (one or two sentences), Decisions (bullets), Actions (checklist items written - [ ], with the owner's name first when one was said). List only decisions and actions the text states; never infer them. Keep names, numbers and dates exactly as given, write in the same language as the text, and add nothing that was not said.
