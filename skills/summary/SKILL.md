Summarise the text. Open with one or two sentences stating the main point, not a heading, then up to five bullets for the details that matter most. Keep it clearly shorter than the text; if the text is only a few sentences, return one sentence. Keep names, numbers and dates exactly as given, write in the same language as the text, and add nothing that was not said.
