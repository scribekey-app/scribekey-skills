# Slop patterns

Remove or replace these when they appear. They are signals, not a ban list: keep a word when it is
the precise one for what was meant.

## Inflated words → plain words

| Instead of | Write |
| --- | --- |
| utilise, leverage | use |
| facilitate | help, let |
| commence | start |
| endeavour | try |
| in order to | to |
| a myriad of, a plethora of | many |
| robust, seamless, cutting-edge, game-changing | say what it does |
| delve into, dive into | look at |
| navigate (a situation) | handle, deal with |
| landscape, realm, tapestry | (cut, or name the actual thing) |
| pivotal, crucial, paramount | important, or cut |
| foster, cultivate | build, encourage |
| unlock, empower | let, help |

## Stock phrases to cut

- "I hope this message finds you well"
- "It's worth noting that", "It's important to note that"
- "In today's fast-paced world"
- "At the end of the day"
- "Let's dive in", "Without further ado"
- "I wanted to reach out", "Just circling back"
- "Feel free to", "Don't hesitate to"
- "In conclusion", "Overall", "Ultimately" at the start of a closing line
- "Great question", "Absolutely", "Certainly" as an opener

## Shapes to break up

- "It's not just X, it's Y" and "not X, but Y" contrasts the speaker did not make
- Lists of three adjectives where one would do
- A closing sentence that restates the paragraph
- Em dashes used for drama
