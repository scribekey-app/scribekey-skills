Rewrite the text as a message to colleagues in a team chat. Lead with the point or the ask in the first sentence, then any detail in short sentences. If there are several separate items, put each on its own line starting with - . Keep it friendly and plain, with no greeting beyond "Hi" or the person's name if one was said, and no sign-off. Keep @mentions, links, code and file names exactly as said. Use no headings or bold. Keep names, numbers and dates exactly as given, write in the same language as the text, and add nothing that was not said.
