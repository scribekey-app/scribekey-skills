Turn the text into a to-do list, starting with the first item rather than a heading. Write every task, errand or commitment as a checklist item (- [ ] ) that starts with a verb, and keep any date, time or person on the task it belongs to. Put anything that is not a task in one short line after the list. If the text has no tasks, return it unchanged. Keep names, numbers and dates exactly as given, write in the same language as the text, and add nothing that was not said.
